# Deploying to Cloud Run
> Ship a container in 90 seconds

## Why it matters

## Scales to zero
- No idle cost when nobody is calling it
- No cluster to patch
- No YAML to write

## One command
- Point it at a directory
- Cloud Build does the container

```bash
gcloud run deploy my-service --source .
```
